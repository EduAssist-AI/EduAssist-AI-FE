## Introduction

Welcome to the EduAssist-AI User Manual! This comprehensive guide will help you navigate and maximize your experience with the EduAssist-AI platform. EduAssist-AI is an innovative educational tool designed to enhance learning through AI-powered summarization of educational content, including videos, slides, and documents.

### What EduAssist-AI Does

EduAssist-AI transforms complex educational materials into easily digestible summaries, helping students and educators save time while improving comprehension. The platform allows you to:
- Create and manage educational courses
- Upload and organize learning materials
- Generate AI-processed summaries of educational content
- Interact with an AI assistant trained on your course materials
- View and manage all your educational resources in one place

## Getting Started

### Creating an Account

1. Visit the EduAssist-AI website and click on the "Sign Up" button located in the top-right corner of the homepage.
2. Fill in the required information including your name, email address, and a secure password.
3. Verify your email address by clicking on the confirmation link sent to your inbox.
4. Once verified, sign in to access the dashboard.

### Logging In

1. Click on the "Sign In" button on the homepage.
2. Enter your registered email and password.
3. Click "Sign In" to access your account.
4. If you've forgotten your password, click "Forgot Password?" and follow the instructions sent to your email.

### Dashboard Overview

Upon logging in, you'll arrive at your personalized dashboard, which includes:

- **Navigation Menu**: Located on the left-hand side for easy access to different features
- **Course Grid**: Displays all the courses you're enrolled in or have created
- **Quick Actions**: Floating "+" button to create new courses or modules
- **Search Functionality**: To search for specific courses or resources

## Creating and Managing Courses

### Creating a New Course

1. From the dashboard, click the floating "+" button at the bottom right corner of the screen.
2. Select "Create Course" from the options that appear.
3. Fill in the course details:
   - Course Name: Enter a descriptive title for your course
   - Course Description: Provide a brief overview of the course content
4. Click "Create" to finalize the course setup.
5. Your new course will appear on the dashboard.

### Course Management Options

Once a course is created, you can manage it using the three-dot menu (⋮) in the course card:

- **Edit**: Modify the course name or description
- **Delete**: Remove the course (Note: This will also delete all modules and associated content)
- **View Details**: Navigate to the course page to see modules and resources

### Joining an Existing Course

1. Click on "View Details" of the course you wish to join
2. Use the invitation code displayed on the course page to join
3. The course will then appear in your dashboard

### Course Details Page

Clicking on any course card will take you to the course details page, which offers:

- Course name and description
- Creation date
- Course status (Active/Inactive)
- Invitation code for others to join
- Module management section
- Back button to return to dashboard

## Managing Modules

### Creating Modules

Modules are subsections of your courses that contain specific learning materials. To create a module:

1. Navigate to the course you want to add a module to
2. Click the floating "+" button at the bottom right corner
3. Select "Create Module" from the form that appears
4. Enter the module name and description
5. Click "Create" to add the module to your course
6. The new module will appear as a card in the course details page

### Module Management

Each module card provides the following options:

- **Edit**: Modify the module name or description
- **Delete**: Remove the module and all associated resources (cannot be undone)
- **View Module**: Access the module to upload resources and use AI features

### Module Details Page

The module details page is your central hub for educational activities and includes:

- Left column: Resource management (upload, view, edit, delete)
- Center column: Main viewing area with different AI-powered features
- Right column: Feature cards for various tools
- Back button to return to the course overview

## Uploading Educational Resources

### Uploading Process

To upload educational materials to a module:

1. Navigate to the desired module
2. In the left column, click "Upload Resource"
3. Select the file type (video, PDF, DOCX, etc.) you wish to upload
4. Choose the file from your device
5. Optionally add tags or descriptions
6. Click "Upload" to process the file

### Supported File Types

EduAssist-AI supports various educational resource formats:

- **Videos**: MP4, MOV, AVI, and other common video formats
- **Documents**: PDF, DOCX, PPTX formats
- **Slides**: PowerPoint, PDF slides
- **Audio**: MP3, WAV formats
- **Text files**: TXT format

### Resource Management

After uploading, you can manage resources in the Resources section:

- **Rename**: Click the "Rename" button to change the resource title
- **Delete**: Click "Delete" to remove the resource permanently
- **View**: Access resources through the center panel when "Resources" is selected

## AI-Powered Features

### Module Chat (AI Assistant)

The Module Chat feature provides an AI-powered assistant trained on your module's content:

1. In the module details page, select "Module Chat" from the right column
2. Type your question about the module content in the chat input
3. The AI assistant will provide answers based on the educational materials in the module
4. Use this feature to clarify concepts, review material, or get explanations

### Summary Notes

Generate and access AI-processed summaries of your educational content:

1. Select "Summary Notes" from the right column in the module view
2. The system will display summaries of all available resources
3. Use these notes for quick reviews and key point extraction

### Summary Management

Comprehensive tool for creating and managing content summaries:

1. Choose "Summary Management" from the right column
2. Select resources to include in the summary
3. Choose summary length: Brief, Detailed, or Comprehensive
4. Optionally specify focus areas (e.g., algorithms, applications, theory)
5. Add custom prompts for specific requirements
6. Click "Create Summary" to generate AI-processed content

### Resource Management Features

- **View All Summaries**: Access all generated summaries for the module
- **Download Options**: Export summaries in PDF format
- **Publish/Unpublish**: Control the visibility of summaries
- **Delete**: Remove unwanted summaries

## Summary Management

### Creating New Summaries

The Summary Management page allows you to generate AI-powered summaries of your educational resources:

1. Navigate to the module and select "Summary Management" from the right panel
2. In the left column, you'll see the "Create New Summaries" section
3. Select the resources you want to summarize using checkboxes
4. Choose the summary length: Brief, Detailed, or Comprehensive
5. Optionally add focus areas using comma-separated keywords
6. Add custom prompts for specific requirements
7. Click "Create Summary" to generate the AI-processed content

### Managing Existing Summaries

The right panel shows all existing summaries with the following capabilities:

1. **View Summary Content**: Click the expand button to see the full summary
2. **Publish/Unpublish**: Toggle the visibility status using the dropdown menu
3. **Download PDF**: Export summaries using the dropdown menu
4. **View Details**: Open a detailed view in a modal window
5. **Delete**: Remove summaries permanently using the delete option

### Summary Types

EduAssist-AI offers three summary types:

- **Brief**: Concise overview with key points
- **Detailed**: More comprehensive coverage with explanations
- **Comprehensive**: Thorough summary with all major concepts

### Summary Actions

Each summary card includes:
- Title and visibility status
- Content preview
- Transcript availability indicator
- Creation date
- Action dropdown menu with options to publish, download, view details, or delete

## Troubleshooting

### Common Issues and Solutions

**Issue**: Cannot upload files larger than expected
- Solution: Check your internet connection and try uploading during off-peak hours. If the problem persists, contact support.

**Issue**: AI summaries are not generating
- Solution: Ensure the source material has sufficient content. Very short or minimal content may not generate summaries.

**Issue**: Can't access the Module Chat feature
- Solution: Verify that your module contains uploaded resources. The AI assistant requires content to provide meaningful responses.

**Issue**: Dashboard not loading properly
- Solution: Refresh the page or clear your browser cache. Try using a different browser if the issue continues.

**Issue**: Login problems
- Solution**: Check your email and password for typos. Use the "Forgot Password" feature if needed.

### System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Stable internet connection
- Minimum screen resolution of 1024x768 for optimal experience
- JavaScript enabled in your browser

### Browser Compatibility

EduAssist-AI is optimized for:
- Chrome 80+
- Firefox 75+
- Safari 13+
- Microsoft Edge 80+

## FAQs

### General Questions

**Q: Is EduAssist-AI free to use?**
A: EduAssist-AI offers both free and premium features. Basic course creation and limited summaries are available for free, while more advanced AI features may require a subscription.

**Q: How accurate are the AI-generated summaries?**
A: Our AI is designed to provide accurate and relevant summaries based on the content provided. While we strive for high accuracy, we recommend reviewing summaries for critical content.

**Q: Can I share my courses with other users?**
A: Yes, you can share courses using the invitation code feature. Each course has a unique code that can be distributed to others.

### Technical Questions

**Q: What file sizes are supported for uploads?**
A: Video files up to 500MB and documents up to 50MB are supported. Larger files may need to be compressed before uploading.

**Q: How long does it take to generate a summary?**
A: Summary generation time varies depending on the content length and system load. Typically, it takes 30 seconds to a few minutes.

**Q: Can I edit the AI-generated summaries?**
A: Generated summaries can be viewed, downloaded, and published/unpublished, but direct editing of the AI output is not available. You can generate a new summary with different parameters.

### Security and Privacy

**Q: Is my content secure?**
A: Yes, we use industry-standard encryption and security measures to protect your educational content and personal information.

**Q: Where is my data stored?**
A: Your data is stored on secure cloud servers with regular backups and compliance with data protection regulations.
